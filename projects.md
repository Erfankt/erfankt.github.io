### 🛣️ Urban Street Network Configuration & Property Crime

Reproducible data-construction pipeline for [Kefayat & Thill (2025), *ISPRS International Journal of Geo-Information*](https://doi.org/10.3390/ijgi14050200) — an empirical multivariate study of how street-network configuration relates to property crime in Charlotte, NC. Packaged as an open-source Python pipeline with a one-click, point-and-click web app so anyone can reproduce or re-run the analysis on their own city data.

[View the repository on GitHub →](https://github.com/Erfankt/urban-network-analysis)
